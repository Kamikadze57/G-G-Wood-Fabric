# G&G Wood Fabric

Цей проєкт — це адаптивний та інтерактивний вебсайт-портфоліо для компанії, що спеціалізується на виробах з дерева. Сайт демонструє широкий спектр послуг, від меблів до дизайну інтер'єрів, і створює візуально привабливе представлення бренду.

Розроблений в рамках 4-го курсу GoITeens, проєкт дозволив закріпити навички, вивчені на курсі, і застосувати їх на практиці для створення повноцінного комерційного продукту. Сайт реалізовано з використанням сучасних технологій та підходів у верстці.

Проєкт включає в себе:
* Адаптивний дизайн, що коректно відображається на різних пристроях.
* Використання сучасних підходів в CSS (SCSS).
* Основи JavaScript для додавання інтерактивності.

Цей проєкт демонструє вміння працювати з HTML, SCSS та JavaScript, а також навички роботи з Git і GitHub.

## Технології, що використовуються

* **HTML5**: Структура сторінки.
* **SCSS**: Препроцесор для стилізації.
* **JavaScript**: Додавання динамічних ефектів та функціоналу.
* **Git**: Система контролю версій.
* **GitHub**: Хостинг репозиторію.
